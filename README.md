# DeMás

Contador personal de horas extras a partir de las marcaciones visibles de tu propia cuenta de Lenox.

Web: https://agustinbarral14.github.io/demas/

## Uso

Instalá el conector desde Mi conexión en DeMás. Requiere Chrome de escritorio y una cuenta de Lenox con acceso a Marcaciones. Iniciá sesión directamente en Lenox; DeMás no solicita contraseñas.

El total central es: extras antes de la entrada y después de la salida, menos tardanzas y salidas anticipadas. Usa el primer y último fichaje de cada día y no descuenta pausas intermedias. El día actual no se trata como una salida anticipada confirmada. Es una cuenta personal, no una liquidación aprobada por el empleador.

## Privacidad

El repositorio contiene únicamente el código y el conector. No contiene fichajes, datos personales, contraseñas ni claves de Lenox. Las marcaciones quedan en memoria dentro de la pestaña. Solo se guarda localmente la preferencia de tema. GitHub Pages sirve archivos estáticos; no hay un servidor que reciba horarios.

## Publicación

GitHub Pages: rama main, carpeta /docs. Las rutas son relativas para funcionar en /demas/.

## Límites

La actualización periódica necesita el conector instalado, la sesión de Lenox abierta y DeMás visible. La interfaz de Lenox puede cambiar o demorar: se rechazan datos incompletos y se conserva la última lectura en caso de error. Conector beta distribuido como extensión descomprimida.
